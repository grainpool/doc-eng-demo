Change Lab — live mode

This page sits behind Cloudflare Access (and the backend re-verifies your identity — two gates). Mutations apply to a working copy, run through the REAL pipeline, and render through the same renderer as the public replay. Every action lands in the audit log under your Access email.

1 · Change a product fact → docs get patched

Flips one of nine allowlisted facts to a closed value in a working copy. The pipeline finds every place the docs state the old value and proposes patches — and a validated patch set opens a real pull request on the estate repo.

2 · Change a doc's text → drift gets detected

Edits one editable unit's body while product truth stays put — the mirror image of the first form. The pipeline reports drift findings, attributes an owner, and the adversarial falsifier suppresses the false positives. No pull request: this path detects, it does not patch.
