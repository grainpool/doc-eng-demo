# CONTRACTS-FROZEN — what Concord may rely on

Frozen 2026-07-26 at `@relay/contracts` **1.0.0**, git tag `relay-contracts-v1`.
Current version **1.3.0** (see the change log in §5).
Relay is a FIXTURE from here on. Concord (Phases 10+) is built against exactly
this surface and nothing else.

## 1. The two permitted endpoints — the ONLY Relay HTTP surface Concord calls

| Endpoint | Response schema (in `@relay/contracts`) |
|---|---|
| `GET /api/product-truth` | `ProductTruthSnapshotSchema` (§3.2) — plus a non-contractual `tier_status` diagnostic field Concord must ignore |
| `GET /api/copy-registry` | `{ entries: CopyEntry[] }` with `CopyEntrySchema` (§8) |

Everything else under `/api/` is Relay-internal and off-limits (invariant
I13, enforced by Concord's coupling test and lint from Phase 10).

## 2. The fact registry and tier assignments

`FACT_REGISTRY` + `TEMPLATED_FAMILIES` in `packages/contracts/src/facts.ts`,
resolved through `matchFactKey()`:

- **Literal keys (23)** — limits (`limit.upload.csv.max_bytes|max_rows`),
  file-type support (`support.file_type.csv|tsv|xlsx`), runtime versions
  (`runtime.python.version`, `runtime.package.{pandas,scipy,statsmodels,matplotlib}.version`),
  terminology (`term.canonical.{task,project,artifact}`), availability
  (`availability.feature.analysis_sessions.platform.{web,ios,android,cli}`,
  `availability.feature.connector_drive.platform.web`), plans
  (`plan.feature.{analysis_sessions,connector_drive}.min_plan`), retention
  (`retention.{artifact,uploaded_file}.days`), and
  `flag.analysis.regression_enabled`.
- **Templated families (5)** — `analysis.operation.<op_id>.enabled` (T0),
  `cli.command.<command_path>.{flags,summary}` (T2, dot-encoded paths),
  `release.<release_id>.changes` (T4, temporal never factual),
  `decision.<decision_id>.record` (T5).

No fact is authoritative in two tiers. Unregistered keys are
`UNSUPPORTED_CLAIM`s, never crashes.

## 3. The CLI surface

`fixtures/cli-introspection.json` — regenerated by CI from the built CLI and
diffed (staleness gate). 21 commands; `usage` equals `--help` byte-for-byte
(invariant I3). This fixture, not the CLI source, is what Concord's `clidocs`
generator reads.

## 4. The `@relay/contracts` version

**1.3.0.** `relay_contracts_version` in every snapshot reports the current version.

## 5. The change rule

Any change to the surfaces above — schema shape, fact key set, tier
assignment, endpoint shape, introspection fixture format — requires a MINOR
version bump of `@relay/contracts` AND a dated entry appended to this file
stating what changed and why. No silent edits. Additive error codes and new
copy entries do not require a bump; anything Concord parses does.
